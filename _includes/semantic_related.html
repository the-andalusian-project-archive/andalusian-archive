{%- comment -%} Semantic neighbours from `_data/semantic_links.json`, built by `scripts/build_semantic_index.py`. The hand-written `related.html` block only links inside one collection and only on explicit join keys (tag, category, co-author, venue, theme). It cannot connect an essay to a lecture that makes the same argument, or a paper to the video where the author summarises it. This include reads the TF-IDF index and shows those cross-collection neighbours.
