Where the data is silent - a video's upload date, a paper's access status where the archive does not mirror the text, a recording's thumbnail - the field is OMITTED, not filled with a plausible value. There is no placeholder text anywhere in the emitted output. 2. No corpus count appears in any node. The node inventory is expressed as an ItemList of the site's own collection index pages, whose URLs are facts, rather than as a number the site owner has not approved. 3. Every `@id` and `url` is absolute and is built from `url` + `baseurl` + the page path, so a node can never disagree with its own canonical link or with the sitemap. 4. A one-level breadcrumb on a flat page (/timeline/, /channel/) states nothing and is not emitted.
