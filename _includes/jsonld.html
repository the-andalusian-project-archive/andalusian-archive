Replaces the single `BlogPosting` node jekyll-seo-tag put on 302 pages, which was the wrong type for every video record, every transcript and every academic paper, and which carried no `author` at all. RULES HELD TO THROUGHOUT THIS FILE 1. A field is emitted only when the page's own front matter or the row it was generated from actually contains it. Where the data is silent - a video's upload date, a paper's access status where the archive does not mirror the text, a recording's thumbnail - the field is OMITTED, not filled with a plausible value. There is no placeholder text anywhere in the emitted output. 2. No corpus count appears in any node. The node inventory is expressed as an ItemList of the site's own collection index pages, whose URLs are facts, rather than as a number the site owner has not approved. 3. Every `@id` and `url` is absolute and is built from `url` + `baseurl` + the page path, so a node can never disagree with its own canonical link or with the sitemap. 4. String values go through `| jsonify`, so a title containing a quote, a backslash or a full-width brace cannot produce invalid JSON. (The corpus does contain such titles: `'"How NOT to be a Critic"'`.) 5. Breadcrumbs are emitted only where the site's own nav states the hierarchy - Home -> collection -> item. A one-level breadcrumb on a flat page (/timeline/, /channel/) states nothing and is not emitted.
