M5 (Phase-3 review, 2026-09-27): the page used to print that string verbatim, so a year-only row read "2020" and a year-month row "2020-03" while the rest of the site writes dates out ("March 12, 2020"). Printing it verbatim fixed a real bug and left a visible inconsistency; this closes both. It must not be re-run through the `date` filter unguarded. Liquid reads an all-digits string as a Unix timestamp, so the year-only value "2020" was rendered as "January 1970" - a publication date this archive does not have. So the string's SHAPE is checked first, and every branch that reaches `date` is a string that contains a hyphen and therefore cannot be read as a timestamp; the year-only branch never reaches it at all: 2020 -> 2020 (no filter; a bare year is a year) 2020-03 -> March 2020 (month and year are known; the day is not, so no day is invented, and the 01 fed to the filter to reach it is never printed) 2020-03-12 -> March 12, 2020 The year-only and year-month shapes are both fatal to Ruby date parsing - `Time.parse("2020")` and `Time.parse("2020-03")` both raise - and Liquid answers a raise by handing the input straight back, which is how a naive fix leaves the page looking unchanged. The guards are numeric, so a value that is not a date at all cannot reach `date` either. Anything else falls through to the raw string, which is what the page printed before. No branch can produce a date the source did not state. {%- endcomment -%} {%- assign pdate = page.publication_date -%} {%- assign pyear = pdate | slice: 0, 4 -%} {%- assign pmonth = pdate | slice: 5, 2 -%} {%- assign pday = pdate | slice: 8, 2 -%} {%- assign pyear_n = pyear | plus: 0 -%} {%- assign pmonth_n = pmonth | plus: 0 -%} {%- assign pday_n = pday | plus: 0 -%} {%- assign pyear_month = pyear | append: "-" | append: pmonth | append: "-01" -%} {%- assign shape_year_only = false -%} {%- assign shape_year_month = false -%} {%- assign shape_full = false -%} {%- if pdate.size == 4 and pyear_n > 1000 and pyear_n < 10000 -%} {%- assign shape_year_only = true -%} {%- elsif pdate.size == 7 and pdate contains "-" and pyear_n > 1000 and pyear_n < 10000 and pmonth_n > 0 and pmonth_n < 13 -%} {%- assign shape_year_month = true -%} {%- elsif pdate.size == 10 and pdate contains "-" and pyear_n > 1000 and pyear_n < 10000 and pmonth_n > 0 and pmonth_n < 13 and pday_n > 0 and pday_n < 32 -%} {%- assign shape_full = true -%} {%- endif -%}
